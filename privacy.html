Privacy Policy

YouTube Studio MCP · Last updated 2 September 2026

YouTube Studio MCP ("the tool") is a personal, single-user command-line application. It runs entirely on its owner's own computer. It has no servers, no backend and no user accounts. This policy explains what Google user data the tool accesses and what happens to it.

What data the tool accesses

After the owner signs in with Google and grants consent, the tool can call the YouTube Data API v3, the YouTube Analytics API and the YouTube Reporting API on behalf of that Google Account. Through these APIs it can read:

  • channel and video metadata belonging to the authorising account
  • aggregate performance statistics: views, watch time, subscriber changes
  • aggregate audience data: retention curves, traffic sources, age and gender bands, country-level geography
  • revenue reports, where the channel participates in the YouTube Partner Program
  • comments on the authorising account's videos

All audience data provided by the YouTube Analytics API is aggregated and anonymous. The tool does not receive, and cannot request, the identity of individual viewers.

The tool can also write to the authorising account's own channels — upload videos, edit video metadata, manage playlists and post comments — when the owner explicitly asks it to.

The tool cannot access channels the authorising account does not own, and it does not read Gmail, Drive, Contacts, Calendar or any other Google service.

How the data is used

Data is used solely to answer the owner's own questions about their own channels, at the moment they ask them. It is not used for advertising, profiling, training machine-learning models, or any purpose unrelated to the tool's stated function.

How the data is stored

API responses are not persisted. They are displayed and discarded.

The one thing stored on disk is the OAuth credential: an access token and a refresh token, written to token.json in a per-channel folder under the owner's home directory on their own machine. These files never leave that machine.

How the data is shared

It is not shared. No data is transmitted to the developer, to any analytics provider, or to any other third party. The only network connections the tool makes are to Google's own API endpoints.

Retention and deletion

Because nothing is retained beyond the stored OAuth credential, deletion is a matter of removing that credential. Deleting the token.json file removes the tool's access immediately.

Revoking access

Access granted to this tool can be withdrawn at any time from Google Account permissions. Once revoked, the stored token stops working and the tool loses all access.

Limited Use disclosure

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
