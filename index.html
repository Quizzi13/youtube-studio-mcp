YouTube Studio MCP

A personal command-line tool that lets its owner read analytics for their own YouTube channels without opening YouTube Studio in a browser.

What it does

YouTube Studio MCP is a local Model Context Protocol server. It runs on the owner's own computer and exposes the YouTube Data API v3, the YouTube Analytics API and the YouTube Reporting API to a local AI assistant, so that questions like "what is the audience retention curve on this video" or "where did last week's traffic come from" can be answered from the command line.

It is a single-user tool. It is not a product, it is not offered as a service, and it has no user accounts of its own.

What it accesses

  • youtube.readonly — read channel and video metadata
  • youtube — manage playlists and video metadata for the owner's channels
  • youtube.upload — upload videos to the owner's channels
  • yt-analytics.readonly — read performance, audience and retention reports
  • yt-analytics-monetary.readonly — read revenue reports

Access is limited to the channels owned by the Google Account that granted it. The tool cannot read anyone else's private channel data.

Where the data goes

Nowhere. The tool has no backend and no servers. Data returned by the Google APIs is displayed on the owner's own machine and is not transmitted to any third party. See the privacy policy for details.

Source

Built on the open-source MCP server pauling-ai/youtube-mcp-server (MIT), published on PyPI as youtube-studio-mcp.
